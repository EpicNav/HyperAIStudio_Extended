HyperAIStudio

HyperAIStudio is a usability layer for Epic Unreal MCP in Unreal Engine 5.8. It helps artists, designers, and programmers connect external coding agents such as Codex, Claude Code, Gemini, Cursor, and VS Code/Copilot to a live Unreal Editor project without learning every MCP setup detail.

One setup button

Configures Unreal MCP, enables useful Unreal-side plugins, generates agent files, and verifies readiness.

External agent workflow

Your configured agent client keeps its own runtime. HyperAIStudio prepares Unreal context, copies the handoff, and opens the selected client from the project root when available. Lifecycle and reconnect guidance is the same for every supported agent.

Editor context handoff

Selected Blueprint/PCG assets, actors, and Blueprint/PCG graph nodes can be packaged into small project-local context files for the agent.

First Run

  1. Use the startup prompt, Tools > HyperAIStudio, Tools > HyperAI Chat, or the HyperAIStudio status bar button.
  2. Press Start Setup from the prompt or from the Setup tab.
  3. Restart the editor if Unreal reports newly enabled plugins.
  4. Verify until readiness shows the required plugins, local MCP server, generated agent files, at least one configured agent, and tools/list reachable.
  5. Ready projects should use the separate docked panel, HyperAI Chat, for daily handoff. Choose a configured terminal-capable agent, type directly in the embedded project-root terminal, and use Stop Agent before switching or when finished. Use Copy Prompt for manual handoff/context fallback. Setup, agent files, MCP profiles, and docs stay in the HyperAIStudio workbench tabs: Setup, Agents, MCP, and Docs.

What HyperAIStudio Generates

  • AGENTS.md: shared project instructions for external agents.
  • CLAUDE.md: thin Claude Code notes that import the shared instructions.
  • .codex/config.toml: Codex MCP config with unreal-mcp.
  • .mcp.json: Claude Code MCP config.
  • .gemini/settings.json: Gemini MCP config.
  • .cursor/mcp.json and .vscode/mcp.json: Cursor and VS Code/Copilot MCP config.
  • .hyperai/scripts/Start-HyperAIStudioEditor.ps1: starts or reconnects the editor.
  • .hyperai/scripts/Wait-HyperAIStudioMCP.ps1: waits for the MCP endpoint and verifies tools/list.
  • .hyperai/scripts/Send-HyperAIStudioPrompt.ps1: copies generated prompt/context instructions and starts the selected CLI or project-root editor when available.
  • .hyperai/docs/HyperAIStudio-TestCommands.md: generated test and connection guidance.
  • .hyperai/README.md and .hyperai/INDEX.md: preserved, managed guidance for the shared project workspace and its useful history.

Shared Project Workspace

Useful agent collaboration belongs in source control under .hyperai/work/YYYY-MM-DD-<clear-context-name>/. Use a clear lowercase kebab-case name and add only the planning, context, prompts, research, decisions, logs, or temporary task files that are actually useful. Do not create generic Planning, Temp, Research, Notes, or Scripts folders in the project root.

Architecture and product decisions use a dated descriptive filename inside the relevant workpackage. Agents update a concise dated log after meaningful work and consult .hyperai/INDEX.md only when prior context matters; simple questions and read-only checks do not need history. Generated scripts live under .hyperai/scripts/, documentation under .hyperai/docs/, durable ownership metadata under .hyperai/state/, and volatile status, journals, pending transactions, and temporary files under the Git-ignored .hyperai/runtime/. Real source, content, and config stay in their normal project locations.

Generated shared instructions, selected client configs, prompts, context, workpackages, decisions, and useful logs are intended for source control. Agent config files are written at the project-root paths where each external agent expects them. HyperAIStudio only writes configs for agents that are enabled and selected for generation. New projects keep Codex enabled by default and leave the other built-in agents off until the user enables them. Agent-specific actions live in the Agents tab, where users can enable/disable agents, regenerate files, open generated files, run visible install commands for missing CLIs or launchers in HyperAI Chat, add custom external agent routes, or copy a starter handoff prompt. Existing JSON client config files are merged when structurally valid. If a JSON config is malformed or incompatible, generation stops without modifying it; use version control to inspect or recover the file. Codex project TOML is updated only inside a delimited HyperAIStudio managed MCP block. Credentials, caches, volatile runtime status, binaries, and raw terminal dumps should not be committed.

Starter Instructions

Paste this into your configured agent client after setup:

My Unreal project is configured with HyperAIStudio. Read the generated instruction file supported by this client and use unreal-mcp for live Unreal Editor actions. If the editor is closed or disconnected, run .hyperai/scripts/Start-HyperAIStudioEditor.ps1 and wait for MCP readiness, even if native tools are not currently exposed. Missing native tools do not prove that the working directory is wrong. Only request an MCP reload or project-root reopen if the endpoint is ready and my task actually requires unavailable Unreal tools. Do not modify assets yet.

Daily Use

From the docked HyperAI Chat panel

  • Use HyperAI Chat for daily handoff: choose a configured agent, keep context on Manual unless you started from a context menu, then type in the embedded terminal or copy the prompt for manual paste.
  • Use the HyperAIStudio workbench tabs for setup, agent configuration, MCP profiles, generated files, prerequisites, and docs.
  • HyperAIStudio embeds a lightweight terminal launcher for terminal-capable agents, but does not interpret terminal output or own agent approvals/history. Stop Agent resets the current terminal session, and Copy Prompt remains available for manual paste fallback.

From the HyperAI Chat overlay

  • Open Tools > HyperAI Chat Overlay for a temporary lightweight chat window without changing the editor layout.
  • Use the Docs tab in the HyperAIStudio panel for website docs, starter instructions, Epic MCP docs, troubleshooting, and MCP profile/provider shortcuts.

From editor context menus

  • Right-click selected Content Browser assets or selected level actors and choose Open Codex With Selection or Open Claude Code With Selection.
  • Right-click selected Blueprint/PCG graph nodes and choose Copy Selected Node Context for a provider-neutral terminal/coding-agent handoff or Smart Auto Comment Selected Nodes for AI-assisted native comments. The local Quick Auto Comment Selected Nodes action can be enabled in HyperAIStudio settings and is hidden by default.

Prerequisites

HyperAIStudio detects and explains the required Unreal-side plugins and common external tools. Install actions run visible commands in HyperAI Chat's embedded terminal after resetting any active agent session, and the command is copied as fallback.

  • Unreal plugins: ModelContextProtocol, ToolsetRegistry, EditorToolset, MCPClientToolset, and Terminal.
  • Agent tools: Codex CLI, Claude Code CLI, Gemini CLI, Cursor launcher, and/or VS Code launcher with Copilot Agent mode. If an installer updates PATH and HyperAIStudio still shows Missing, restart Unreal Editor so the running editor process can see the new executable path.
  • Editor-agent docs: Cursor MCP docs and VS Code MCP docs.
  • Community MCP and Gemini CLI support: Node.js 20+, npm, npx, Git, and optionally uv for Python-based MCP servers.

MCP Profiles

unreal-mcp is the single execution server for live Unreal Editor actions. HyperAIStudio discovers Epic's available toolsets at runtime and adds only independently validated gap or compound tools through Epic's supported Toolset Registry path. Extra community MCP servers can be imported or added in the MCP tab and exported to selected agent config files. HyperAIStudio does not proxy normal MCP traffic; the external agent chooses tools from the generated configuration and instructions.

  • For HTTP/Streamable MCP entries, use Test to run a non-destructive initialize and tools/list check.
  • For command/stdio MCP entries, use Test to validate that the configured command exists on PATH. The external agent client still owns launching that server.
  • Use Import Profile to import a shareable hyperai.mcp.v1 profile, or use Add / Edit for a local custom entry.
  • Imported profiles can include setup notes, install commands, documentation URLs, domains, and agent instructions. Secret environment values are not imported.

Safety And Limits

  • HyperAIStudio is editor-only and targets Unreal Engine 5.8.
  • Epic Unreal MCP is experimental and local HTTP/SSE only.
  • Do not expose the MCP endpoint beyond localhost.
  • Unreal MCP tool calls execute serially on the game thread, so agents should not issue overlapping editor tool calls.
  • HyperAIStudio does not provide licensing, accounts, cloud services, an execution bridge, or its own agent model/runtime. The retired Hyper UE TCP/stdio/HTTP runtime is never started or used as fallback.

Troubleshooting

  • If setup enabled plugins, restart Unreal Editor and run setup again.
  • If the editor crashes, run .hyperai/scripts/Start-HyperAIStudioEditor.ps1 from the project root.
  • If MCP is not reachable, run .hyperai/scripts/Wait-HyperAIStudioMCP.ps1 -TimeoutSeconds 90 and read .hyperai/runtime/hyperai-status.json.
  • If the endpoint is ready but the current agent client does not expose native Unreal tools, continue any work that does not need those tools. Reload MCP connections or reopen the project root only when the requested task requires them.
  • For protocol debugging, run npx @modelcontextprotocol/inspector, choose Streamable HTTP, and connect to http://127.0.0.1:8000/mcp.
